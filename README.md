# 📈 Crypto Futures Leverage & Liquidation Calculator

An open-source Android utility built with **Kotlin** and **Jetpack Compose** to calculate liquidation prices, risk-to-reward metrics, and simulate Take-Profit / Stop-Loss targets for crypto futures trades.

### ✨ Features
- **Long & Short Position Modes:** Instant risk metrics calculation.
- **Liquidation Price Estimator:** Incorporates leverage and maintenance margin rates.
- **TP / SL Simulator:** Real-time profit and loss calculations for exit targets.
- **Pure Material 3 Design:** Built entirely in Jetpack Compose with Dark Mode UI.
